# Tourism Explorer 🌍

Tourism Explorer is a **standalone HyperDart component** built to help users discover tourist attractions and places of interest through natural-language search queries.

It integrates seamlessly with the HyperDart search platform and uses the Geoapify Places API to fetch live location-based results. Users can explore attractions, museums, temples, monuments, parks, and other landmarks, view place details, and open locations directly in Google Maps.

 **Key Features**
- Natural-language tourism search
- Live location-based attraction discovery
- Category-based filtering
- Place details and address information
- Direct Google Maps links

 Built using React, JavaScript, HyperDart, Node.js, and Geoapify.
